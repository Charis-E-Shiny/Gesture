═════════════════════════════════════════════════════════════════════════════
📦 WHAT THE SCRIPT DOES (Automatically)
═════════════════════════════════════════════════════════════════════════════

    ✅ Clones WLASL repository
       └─ Gets official ASL video metadata
    
    ✅ Downloads videos from YouTube
       └─ Auto-installs yt-dlp if needed
       └─ Handles failures gracefully
    
    ✅ Organizes into proper structure
       └─ Creates train/val/test folders
       └─ 70% / 15% / 15% split
       └─ Maintains gloss integrity
    
    ✅ Validates all data
       └─ Checks videos can be read
       └─ Verifies frame rates
       └─ Detects corrupted files
    
    ✅ Generates configuration
       └─ metadata.json (video listing)
       └─ gloss_vocab.json (vocabulary)
       └─ dataset_config.json (stats)
    
    ✅ Cleans up temporary files
       └─ Removes WLASL repo
       └─ Removes temp downloads
       └─ Keeps only organized data

⚡ QUICK START COMMANDS
═════════════════════════════════════════════════════════════════════════════

For testing (fast):
    python setup_wlasl_dataset.py --num-glosses 50
    └─ Downloads only 50 signs (~5GB, 20 minutes)

For production (comprehensive):
    python setup_wlasl_dataset.py
    └─ Downloads all available signs (~100GB+, 6+ hours)

For custom setup:
    python setup_wlasl_dataset.py --num-glosses 200 --min-videos 20
    └─ 200 signs, require 20+ videos each

❓ QUESTIONS?
═════════════════════════════════════════════════════════════════════════════

    Q: Do I need to install anything?
    A: No! The script installs dependencies as needed.
    
    Q: Can I stop the script and resume?
    A: Not recommended - it's all-or-nothing per run.
    
    Q: What if a video fails to download?
    A: Script continues. YouTube videos sometimes disappear - normal!
    
    Q: Can I use fewer glosses for faster setup?
    A: Yes! Use: python setup_wlasl_dataset.py --num-glosses 50
    
    Q: Will it work on my computer?
    A: If it runs Python & has internet, yes! Needs 100GB+ free space.
