## Module Descriptions

### models_encoders.py
**Classes:**
- `HandEncoder(nn.Module)` - Encodes hand landmarks
- `FaceEncoder(nn.Module)` - Encodes face mesh points
- `PoseEncoder(nn.Module)` - Encodes body pose

**Key Components:**
- Linear embedding layer
- Transformer encoder (2 layers, 8 heads)
- Positional encoding

**Inputs:** (batch, seq_len, input_dim)
**Outputs:** (batch, seq_len, 512)

### models_fusion.py
**Classes:**
- `MultiHeadCrossAttention(nn.Module)` - 6-head cross-attention
- `CrossModalFusionTransformer(nn.Module)` - Multi-modal fusion

**Key Components:**
- Concatenation of 3 modalities
- Cross-attention between modalities
- Self-attention on fused representation
- Layer normalization

**Inputs:** 3x(batch, seq_len, 512) for [hand, face, pose]
**Outputs:** (batch, seq_len, 512) fused representation

### models_conformer.py
**Classes:**
- `ConformerBlock(nn.Module)` - Single conformer block
- `ConformerStreamingEncoder(nn.Module)` - Complete encoder
- `DepthwiseConv1d(nn.Module)` - Depthwise convolution

**Key Components:**
- Feedforward modules (2x)
- Multi-head self-attention
- Conv1d with GLU
- Depthwise convolution
- Causal masking for streaming

**Inputs:** (batch, seq_len, 512)
**Outputs:** (batch, seq_len, 512)

### models_rnnt.py
**Classes:**
- `RNNTTransducer(nn.Module)` - RNNT model
- `RNNTLoss(nn.Module)` - Loss computation

**Key Components:**
- Embedding layer for gloss tokens
- LSTM prediction network
- Joint network (concat + tanh + linear)
- CTC-style loss

**Inputs:** 
- Encoder output: (batch, seq_len, 512)
- Gloss tokens: (batch, target_len)
**Outputs:** (batch, seq_len, vocab_size)

### models_translator.py
**Classes:**
- `TransformerTranslator(nn.Module)` - Seq2Seq translator
- `TranslationLoss(nn.Module)` - Translation loss

**Key Components:**
- Embedding layers (src + tgt)
- Positional encoding
- Transformer encoder-decoder
- Output projection
- Causal masking for decoder

**Inputs:**
- Source (gloss tokens): (batch, src_len)
- Target (English tokens): (batch, tgt_len)
**Outputs:** (batch, tgt_len, english_vocab_size)

### data_extractor.py
**Classes:**
- `MediaPipeLandmarkExtractor` - MediaPipe interface
- `LandmarkDataset(Dataset)` - PyTorch dataset
- `LandmarkCollator` - Custom batch collator

**Key Functions:**
- `extract_landmarks(frame)` - Single frame processing
- `process_video(video_path)` - Batch video processing
- Handles hand, face, pose landmarks

**Output Format:**
- Hand: (seq_len, 126) - 21 points × 3 × 2 hands
- Face: (seq_len, 1404) - 468 points × 3
- Pose: (seq_len, 99) - 33 points × 3

## Configuration Keys

### MODEL_CONFIG
- `vocab_size`: ASL gloss vocabulary (default: 1000)
- `english_vocab_size`: English vocabulary (default: 5000)
- `hidden_dim`: Model dimension (default: 512)
- `num_heads`: Attention heads (default: 8)
- `num_layers`: Model layers (default: 4)
- `dropout`: Dropout rate (default: 0.1)

### TRAINING_CONFIG
- `device`: 'cuda' or 'cpu'
- `batch_size`: Training batch (default: 4)
- `num_epochs`: Total epochs (default: 100)
- `learning_rate`: LR (default: 1e-3)
- `patience`: Early stopping (default: 10)

### INFERENCE_CONFIG
- `max_buffer_size`: Frame buffer (default: 30)
- `target_fps`: Webcam FPS (default: 30)
- `confidence_threshold`: Min confidence

### DATA_CONFIG
- `train_dir`, `val_dir`, `test_dir`: Paths
- `target_fps`: Target FPS
- `frame_size`: Resize dimensions
