# WLASL DATASET SETUP - QUICK REFERENCE

## 🎯 One-Command Solution

```bash
python setup_wlasl_dataset.py
```

**That's it!** This one command will:
- Clone WLASL repo
- Download videos
- Organize train/val/test
- Validate data
- Generate configs
- Clean up

---

## ⚡ Quick Options

```bash
# Download only 50 glosses (faster testing)
python setup_wlasl_dataset.py --num-glosses 50

# Download 200 glosses
python setup_wlasl_dataset.py --num-glosses 200

# Require at least 20 videos per gloss
python setup_wlasl_dataset.py --min-videos 20

# Use custom output folder
python setup_wlasl_dataset.py --output ./my_data

# All together
python setup_wlasl_dataset.py --num-glosses 100 --min-videos 15 --output ./data
```

## ❌ Common Issues & Fixes

| Issue | Fix |
|-------|-----|
| Git not found | Install from https://git-scm.com |
| yt-dlp fails | Auto-installs, but can `pip install yt-dlp` |
| Too slow | Use `--num-glosses 50` |
| Disk full | Use fewer glosses, or expand storage |
| Videos fail | Normal - script continues, YouTube videos may disappear |
